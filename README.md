# T3x Dominion

Seamless turn-based hex strategy game.

**Presented by Futuret3Ch and the T3x Ecosystem**

## Play

Open `index.html` in any modern browser, or deploy to Vercel.

## Features

- Smooth 60fps Canvas rendering
- Hex grid conquest
- Resource management (Energy, Data)
- Unit deployment and movement
- Cinematic trailer on launch
- Clean futuristic UI

## Promo Materials

Generated key art, posters, and logos available separately for download.
